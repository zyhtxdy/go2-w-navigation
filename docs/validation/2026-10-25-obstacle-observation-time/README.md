最终代码完成一轮完整录包回放：**18 次普通规划请求全部生成有效路径**；3 次地图外负对照全部拒绝。
没有超时、未就绪跳过或挂起请求。本机 **418 项测试通过**，没有失败或跳过。

本轮不启动控制器、行为树、恢复行为或速度桥接；位姿跟随录包轨迹，机器人不会沿新路径运动。

## 修改

| 项目 | 行为 |
| --- | --- |
| 地面历史 | 继续保留约 2 秒输入用于地面拟合与支撑提取 |
| 实测障碍年龄 | 独立参数 measured_obstacle_decay_time，默认 0.6 秒，按输入扫描源时间筛选 |
| 原始观测时间 | 每个实际返回点保留 observation_sec / observation_nanosec，不被后续分析的 header 覆盖 |
| 实测障碍刷新 | 随每次地形处理发布，不再等待较慢的 terrain_publish_interval |
| 混合流多帧确认 | 同一体素仅在实际配准扫描时间前进时增加实测确认次数 |
| 过期记录 | 保留有限区域内的时间标记，防止同一旧点过期后重新激活 |
| 新危险 | 过期的实测记录不会屏蔽新的合成危险；已确认危险升级为实测时不丢占用 |
| 时间回退 | 小范围旧序帧丢弃；超过地面历史跨度的回退清空历史与确认状态 |
| 规划诊断 | 增加 source_observation_stamp_ns，区分点的观测时间与障碍快照时间 |
| 可选证据记录 | 保存碰撞前后各 3 秒原始云、配准云、实际障碍快照、对应时刻 TF 和里程计 |

局部 `/terrain/obstacles` 与 `/terrain/clear_scan` 保留原来的完整危险分类。
支撑面、固定地图、机器人外廓、碰撞距离、坡度和台阶限制没有放宽。
离线规划器仍以最新实时快照替换动态占用；没有再叠加一层新的障碍保留时间。

“源观测时间”取自输入 `/cloud_registered_body` 的 header，FAST-LIO 将其设为当前扫描结束时间。
它与 `/hesai/points` 的原始 header 分别记录，不能由此证明雷达与本体 IMU 已做硬件时间同步。
空间簇检测仍利用地形历史，不能把它称为独立的单帧障碍簇确认。

0.6 秒是待真机验证的初始年龄窗口，不是严格墙钟清除期限；实际撤销还受处理、发布与传输延迟影响。
新实测障碍没有增加多帧入场等待。两个入口 odom_fusion.launch.py、offline_nav.launch.py 均可覆盖该参数，
必须大于 0 且不超过 history_decay_time。

## 查到的原因

### 历史点确实反复参与了障碍占用

完整证据的 2 秒对照轮中，第 30 秒 G3 因实测点约 `(3.369, -0.546, -0.114)` 被拒绝。
该点发布时源观测年龄约 **1.799 秒**，请求时约 **2.046 秒**。这是内部时间记录，未用外部测量对照。
它来自以前的实际扫描，不能因为后续点云 header 更新，就把它算作重新观测到。

对该轮捕获的 20 张实测障碍快照逐点读取原始 CDR：共 87387 个点记录，其中 57088 个超过 0.6 秒，
最大年龄约 1.999868 秒。这些是跨快照的点记录，包含重复点，不是独立障碍数量。
0.6 秒试验轮捕获的 10 张快照、15863 个点记录，超过 0.6 秒的为 0，未来时间和未知时间均为 0。
完整检查见 observation_age_audit.json。

### 发布周期还会额外拖延清除

只改年龄、仍沿用慢发布周期的试验轮有 17/18 次普通规划成功，剩下的是第 30 秒 G5：

| 事件 | 记录时间（秒） |
| --- | ---: |
| 点的实际配准扫描源时间 | 1791625420.123335838 |
| 障碍快照 header | 1791625420.422509908 |
| 规划请求 | 1791625420.951866439 |
| 下一张不含该邻域的快照 header | 1791625421.022588729 |

该点发布时年龄约 0.299 秒，符合筛选窗口；规划请求时已约 0.829 秒，旧快照还未被替换。
因此最终把实测障碍发布从慢地形发布周期中拆出。地面与支撑面的原发布周期保持。

该邻域在 6 张不同源时间、不同内容的配准扫描中出现，跨度约 0.501 秒。
所以不能把这些回波一律认定为误报，也没有通过删除该位置的点来让规划通过。
原始 Hesai 云缺少 hesai_lidar 到 map/base_link 的 TF，无法直接定位原始回波来源；
原始云“命中数 0”在这个条件下表示无法计算，不能解释为传感器没有看到障碍。
没有证据确定它来自人、机器人自身或反射。
