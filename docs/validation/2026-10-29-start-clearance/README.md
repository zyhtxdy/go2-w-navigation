# 起点附近固定障碍体素细化

2026-10-29，本机修改、编译、固定输入对照和传感器录包回放。没有连接 NX，没有启动控制器、速度桥接或机器人运动。

## 改动范围

起点附近原来的矩形检查将固定障碍点所在的整个 10 cm 体素当作障碍。
工作空间配置现启用 `near_start_static_refinement_radius: 0.60`，
在本次请求起点周围 0.6 m 内，用体素内**所有保存点**的 XY 包围盒加
`near_start_static_obstacle_margin: 0.02` m 复核原体素碰撞。
包围盒保留原体素边界，只有空的 XY 量化区域可能被放行。

- 没有改变配置车身的长宽、高度和 Nav2 外廓。
- 没有删除地图点、改变地图哈希、扩大目标容差或忽略起点障碍。
- 转向、平移过程和竖直体素检查保留。
- 当前体素出现实时观测时保留原整块体素检查，未知／合成实时障碍同样不放宽。
- 起点区域外保留原整块体素检查，搜索每条边不会重设区域中心。
- 不可变搜索快照、返回前最新地图检查、缓存路径和有效性服务采用一致规则。
- 插件参数默认半径为 0（关闭），工作空间的规范参数文件启用 0.6 m；设回 0 即恢复原规则。
- 在线模式没有固定障碍层，本次细化不会放宽它的实时障碍检查。

此调整减少的是固定图的栅格量化保守性，不构成真实无碰撞的证明。
2 cm 是此次模型参数，不是雷达误差或整机安全间隙的实测标定值。
