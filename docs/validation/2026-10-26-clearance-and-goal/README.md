# 2026-10-26 路径净空评分与旧回波拦截修复

本轮按用户要求在本机完成两项工作：路径简化继续考虑障碍净空；核对上一轮唯一未通过的 G5，并修复已确认的观测年龄遗漏。没有连接、修改或同步 NX，没有真机运动测试。

## 路径拉直和切角保留净空偏好

原路径优化只比较长度和转角，可能把 A* 避开障碍软代价区的路线重新拉近障碍。现在评分为：

`路径长度 + 转角平方代价 + 沿途障碍软代价积分 × 原有 obstacle_cost_weight`

- 使用规划器同一份静态与实时障碍软代价场。净空项是偏好代价，不是另一个碰撞半径，也不表示测得的净距离。
- 沿每条边的体素边界分段积分，避免加密路径点后改变评分，或跳过狭窄的代价区域。
- 从地面上一格检查到车身高度，低于名义规划节点高度的障碍也参与评分。
- 保留完整搜索路线作为候选初始路线。仅在通过地面和完整车身检查后，才与原简化路线比较总评分，防止优化前已经丢失避障偏好。
- 拉直、切角的每个候选仍需完整地形和矩形扫掠检查；起点、目标和所选盲区连接保持约束。没有调小外廓、padding 或硬膨胀半径。
- 无法在采样预算内算出有限评分时，保留已验证输入；不会把未知评分当作零代价。

本轮没有改变原有“有效直达路线优先”的快速分支，也没有保证所有路线都严格位于通道几何中线。当前改进针对搜索路线后续被拉直、切角时丢失净空偏好的问题。

固定几何例子使用同一障碍、地面和带 padding 的矩形外廓 `x=±0.41 m, y=±0.26 m`：原几何评分把路线拉成贴近障碍软代价区的直线；新评分保留安全绕行并缓和拐角。两条路线均通过外廓检查。沿途软代价积分由 **0.158228 降至 0**，这是软件代价值，不是真机间距或定位精度。

## G5 的原始回波证据

分析输入是上一轮 `replay_verified/obstacle_evidence` 保存的原始 CDR 和源时间戳对应的变换，没有重新录制或改变该窗口。

失败请求时，碰撞观测的帧源时间距请求约 **0.831878 秒**；当时规划器使用的障碍快照仅旧约 **0.332054 秒**。快照生成时该观测年龄约 0.50 秒，仍在地形模块 0.6 秒保留范围内；等到规划请求检查目标时，它已经过期。原逻辑只在地形生成快照时过滤点龄，规划器仍可能使用尚未被下一帧替换的旧观测。

回波核对结果：

- 对应原始 `/hesai/points` 的记录为 676，逐点时间范围约为 `1791625420.023001～1791625420.123336`，与配准帧结束时间匹配。使用当前配置外参做刚体比对，附近存在原始回波。
- 同源配准帧中，目标点 15 cm 范围内有 152 个点；之后该范围逐渐不再有当前帧回波。请求前最近一帧的最近点距原碰撞点约 0.61 m。
- 原碰撞点比附近地图支撑面的中位高度约高 0.58 m。这不符合仅有几毫米地面起伏的解释。
- 周边配准点与已有地图实测障碍的邻近关系变化远小于上述目标邻域的变化，支持“短时前景回波移开”的解释，但不能确定物体身份。

这些都是已有估计坐标下的软件比对，没有外部测量。原始点刚体比对没有复现逐点 IMU 去畸变，约 1 cm 的匹配距离不能当作外参标定精度；原始 `hesai_lidar -> map` 精确 TF 未保存。这里的观测时间来自配准源帧结束时间，不是逐束激光的发射时间。

结论是：有原始回波依据，不能按地面噪点直接删掉；**已经超过原本配置的保留时间、却仍参与规划**的问题可以修复。

## 规划时补齐观测年龄检查

离线固定地图模式在全局规划和剩余路径验证前，再按当前 ROS 时间检查原观测年龄，默认与地形模块保持相同的 **0.6 秒**。

- 仅对有有效观测时间戳、来源为纯实测的动态体素过期处理。
- 固定地图障碍保留；与动态观测重叠时恢复固定层记录。
- 无时间戳、未来观测、未知来源和混合来源不凭年龄删除。
- 同体素内以最新观测为依据，旧观测不能覆盖新观测续期。
- 不改变输入流时间戳水位、epoch 或健康心跳。原来的断流、定位失效和取消保护继续生效。
- 写锁中过期后转为共享快照时，复查更新代数及 epoch；若期间有新数据或重置，则重新核对，避免把重新插入的旧点暴露给规划。

离线启动和回放将 `measured_obstacle_decay_time` 同时传给地形节点及规划器的 `live_obstacle_max_observation_age`，防止两端配置分离。在线模式的原混合障碍保留策略没有改变；净空评分则适用于共享规划器的在线和离线路线。
