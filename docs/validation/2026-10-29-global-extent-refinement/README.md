## 当前配置与含义

当前全局规划生成供局部控制器跟踪的几何引导路径。

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `check_in_place_turn_sweeps` | `false` | 不要求在每个折点原地转过所有中间朝向 |
| `refine_static_obstacle_extents` | `true` | 整条路径按固定体素内全部保存点的范围复核 |
| `static_obstacle_extent_margin` | `0.02` m | 固定点范围的 XY 余量 |
| `near_start_measured_refinement_radius` | `0.80` m | 起步附近纯实测实时体素复核的范围 |
| `near_start_measured_obstacle_margin` | `0.03` m | 实时实测点范围的 XY 余量 |

仍检查当前实际朝向下的起点矩形、请求朝向下的终点矩形，以及每段方向下的完整矩形平移通道。
没有缩小车身、取消高度检查、删除障碍点或扩大目标容差；支撑、坡度、高差和输入时效门控保留。
未知、合成及混合实时来源保持整块体素检查；远处实时体素同样不细化。
这些厘米值是软件模型余量，没有当作传感器精度或实测整机安全间隙。

局部 Rotation Shim 与 MPPI 的参数和车身避障保持原样。全局路径不再保证所有折点的
原地转向机动可执行；局部控制可能停车、拒绝执行或需要重新规划。
因此当前“生成路径成功率”不能用作真机到点成功率，也不能与原严格机动标准当作同一验收指标。

## 搜索与数据一致性

- 引导模式的后备搜索按位置和地面层合并状态，不再为每个到达朝向重复展开。
- 该模式后备搜索不带依赖历史朝向的转向代价，每条边仍经过完整矩形通道检查。
- 严格机动模式仍保留朝向状态和转向代价。不同地面高度层没有合并。
- 已有可行直线路径时跳过不会改善现有终点选择的重复候选，选择规则保持不变。
- 没有增加搜索时间预算。
- 实时范围保存所有仍有效观测点，固定与动态共用体素时合并两者范围。
- 未知／合成来源不会被新测量伪装成纯实测范围；过期、替换、重启及快照同步维护范围。
- 搜索、最新地图复核、缓存和路径有效性服务采用同一配置。
