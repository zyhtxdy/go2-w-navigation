## 修改了什么

| 修改 | 最终行为 | 原因 |
| --- | --- | --- |
| 起点网格中心处理 | 当前列有支撑时允许移除到格子中心的多余折线 | 避免几厘米折线引入额外起步转向 |
| 起点连接检查 | 离线候选先检查初始朝向和矩形转向扫掠 | 避免选中中心净空足够、实际外廓受阻的连接 |
| 近墙起步回退 | 原路线外廓失败后最多尝试 8 个其他真实支撑起点 | 允许先沿安全连接走开，再转向 |
| 回退范围 | 额外单次搜索最多 50000 节点；0.25 秒后不再开始下一次重试 | 限制额外搜索工作量；单次搜索没有新增墙钟硬超时 |
| 路径有效性 | 对本节点最新输出的完整相同路径保留已验证起点连接，并重新检查碰撞 | 防止生成与后续检查选择不同连接 |
| 离线实时输入 | 全局规划默认订阅 /terrain/obstacles_measured_global | 固定地图负责已知地形，实时实测回波更新障碍占用 |
| 局部输入 | 继续使用完整 /terrain/obstacles 和 /terrain/clear_scan | 保留局部实时地形危险检查 |
| 目标拒绝诊断 | 区分无支撑、高度不符、净空受阻，并记录候选 | 查清原先笼统的“无安全目标地面” |
| 导图诊断 | 新增 terrain_cells.csv，逐格记录拟合、回波和拒绝原因 | 能从实际危险点追到单格原因 |
| 可选地面恢复 | 仅离线导图显式开启；原拟合失败后用多数独立格的实际回波拟合 | 修复稀疏格的分位高度受干扰问题 |
| 下层保护 | 每个恢复候选都检查中心格最低实际回波 | 防止上方平层覆盖真实低层陡坡或台阶 |

替代连接先通过连续地面、坡度、台阶和障碍检查；输出路线还须通过完整矩形扫掠检查。
机器人外廓、坡度上限、台阶上限、目标投影容差没有缩小或放宽。在线入口与实时地形恢复默认行为保持。

## 剩下 3 次失败

全部发生在第 30 秒一组，诊断来源均为 /terrain/obstacles_measured_global：

| 目标 | 拒绝原因 | 保留的证据 |
| --- | --- | --- |
| G3 | 路线矩形外廓碰撞 | 实测回波约 (3.369, -0.541, -0.111) |
| G4 | 路线矩形外廓碰撞 | 实测回波约 (2.334, -0.551, 0.169) |
| G5 | 目标候选净空受阻 | 实测回波约 (2.335, -0.788, 0.181) |

这些是 map 坐标下的内部数据。measured_return 表示高于拟合地面的实际回波，不能仅凭
这个标签确认它来自人、狗自身、固定物体或反射。没有删除这些回波来提高统计值。
逐项原文和来源时间保存在 summary.json 的 remaining_failures 及逐项规划报告。

## 结果边界与试验记录

此前变更前的联合回放是 6/18。此次最终代码搭配原地图的一轮为 10/18，搭配保护版新图
的一轮为 15/18。录包异步播放，各轮定位和动态障碍窗口略有不同，不能把差值解释为严格
冻结快照 A/B 的提升幅度，也不能将它外推到其他场地。

中间轮还出现过 8/18、12/18。未加下层保护的试验图曾达到 17/18，但审查发现双层陡坡
会被上层覆盖的问题，已修复并归档该试验图；**17/18 不作为最终结果**。所有轮次保留在
summary.json，旧试验地图的归档位置记在 map_archives.json。

本轮没有启动控制器、行为树、恢复行为或运动桥接。机器人位姿跟随录包中的遥控轨迹，
不会沿新生成的路线运动。未验证闭环跟踪、真实到点、独立采集地图重定位或隧道巡检。
当前离线入口强制关闭旧路径复用；以后若重新开放复用，需要补验证复用输出与连接缓存的一致性。
