## 逆模型

使用 0.10～0.40 的七个档位均值、每档等权最小二乘：

```text
w_ekf = 1.133298444 * u - 0.029350016
u = 0.882380105 * w_target + 0.025897871
```

七个均值的拟合 RMSE 为 0.003064 rad/s，R² 为 0.999270。
这是本组均值的拟合残差，不是独立实测精度，也不是补偿后的验证结果。
0.25 附近已接近指令，0.30 以上平均反馈高于指令，因此逆模型允许小幅增加或减小角速度。

## 代码行为

桥接默认开启角速度补偿。0.05～0.40 的目标绝对角速度使用完整逆模型；
0～0.05 用 smoothstep 引入偏置，零值始终为零。
0.40～0.45 将边界修正平滑退回零，不再外推斜率；达到 0.45 后原样传递。
这是连续适用范围处理，不是桥接总限速；这些过渡和补偿后的实际运动尚未验证。
