# 离线导航取消与支撑连接修复（2026-10-21）

## 修复范围

- 重定位的全局检索和全候选核验在同一个后台线程顺序执行；轻量跟踪使用独立前台线程。
- 新鲜完整全局配准可直接作为全局核验测量；超过原 3 s 新鲜度预算的检索结果仅作初值，再对新扫描完整核验所有候选。
- 已定位时由后台结果提供地图变换初值，前台仍对当前扫描真实配准，不靠重写旧位姿时间戳维持有效。
- 初次定位保留三个不同扫描的全局质量与一致性确认。新增独立 confirmation_timeout，正常配置 3 s；tracking_timeout、max_input_age 仍为 3 s。
- 过期后台结果被丢弃，不刷新全局核验有效期；全局核验 8 s 看门狗、质量、歧义、退化、跳变和代次/输入 epoch 保护保留。
- 离线启动根据地图记录的支撑网格间距调整候选连接半径，当前 0.20 m 支撑/0.10 m 规划格对应 0.30 m。在线配置保持 0.25 m。
- 不添加支撑、不填补缺口，连续地面、坡度、台阶、障碍和完整外廓检查保留。
- 定位门控失效新增日志，写明触发取消的原因；恢复时提示已取消任务需要重新下发。原取消保护保留。
