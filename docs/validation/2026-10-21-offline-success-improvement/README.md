# 离线导航成功率相关修复与验证

日期：2026-10-21。针对上一轮离线导航日志中的起点附近连续支撑拒绝、矩形外廓拒绝和全局校验超时改进。原始诊断见 [失败记录](../2026-10-21-latest-navigation-failures/README.md)。

## 改动

### 起点连接与最终连续支撑检查一致

新增 `retain_start_projection_bridge`，公共配置默认 `false`，只有离线入口的私有参数副本启用。

原逻辑在机器人到已选支撑起点的连接途中，一旦附近偶然出现支撑就结束盲区连接；随后稀疏区的小空隙会使最后的路线检查失败。现在仅保留实际选定的笔直起点连接，且在简化、加密后保留其终点。

- 机器人当前 XY 列已有直接观测支撑时，不使用此例外。
- 连接距离和累计路长不能超过原起点投影半径。
- 没有保留选定起点、连接弯折或超长时，不使用此例外。
- 连接中的已观测高差、坡度、障碍和外廓仍检查。
- 到达选定起点后，后续支撑缺口仍拒绝。

不扩大 `support_radius`，不修改固定地图，不将未知地面填成支撑。仍依赖原近场盲区连接假设，不能从软件检查证明未观测区域实际有地面。

### 离线目标外廓预检查与安全路线回退

- 在精确目标 XY 合并候选之前，检查指定朝向的矩形外廓。
- 精确目标中心可通行但角部碰撞时，保留原 0.20 m 目标投影范围内的其他安全支撑候选。
- 全部落点都碰撞时，明确诊断 `goal_orientation_footprint_collision`。
- 简化路线的矩形转向扫掠失败时，最多回退一次到原始搜索路线；重新验证连续地形、障碍和整条矩形扫掠后才返回。

没有扩大目标容差，没有删除实测障碍，没有关闭合成地形标记或完整碰撞检查。这些目标选择与回退仅在 `use_static_map=true` 时生效。无法从历史日志确认每个实时障碍点对应什么实物，因此本轮没有猜测并屏蔽某类实测点。

### 定位后台校验提前调度与持久诊断

根据上一轮完整后台计算耗时和剩余全局期限，必要时提前启动下一轮，降低慢任务结束后继续固定等待造成超时的概率。后台结果已过期时，只保留完整候选池作为下一帧的初值，对新扫描重新评分，不发布旧位姿、不用旧分数刷新有效期限。

保留 3 秒输入/跟踪门限、8 秒完整全局校验期限、全部候选歧义检查、连续确认、跳变检查和 epoch/generation 屏障。

补充后台输入时间、任务阶段、耗时、质量、拒绝原因和全局校验年龄；接近期限或定位失效时写普通 ROS 日志。`global_result_input_age_s` 是后台计算完成时的输入年龄，不是每次发布时的实时年龄。
