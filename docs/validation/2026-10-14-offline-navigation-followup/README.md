## 已修改

- 分开判断定位有效与导航就绪。仅实时地形断流时仍发布有效定位 TF，同时阻断速度。
- 过期定位、坏姿态、非法时间戳、时钟回退会使定位无效；保留具体定位拒绝原因。
- 确认帧超过 3 s 间隔重新计数，避免暂停前的确认直接用于恢复。
- 速度回调不能在定时器发布 TF 之前自行把导航从暂停变为就绪。
- LIO 历史限制为最近 10 s，重复时间戳不增加历史；仿真时钟切换/回退清理历史和 TF。
- 重定位缓存相同目标点集合的协方差、搜索树和法向；源协方差每个查询只算一次。
  缓存上限 8 份、合计 20 万目标点。候选集、迭代和质量门槛保持原值。
- 离线入口默认双线程计算候选，按原候选顺序合并；独立观察入口仍默认单线程。
- 修复确认超时：等待超时从结果完成时计算；测量帧间隔、输入新鲜度和定位有效期
  仍使用原始测量时间，不延长过期定位的有效期。
- 增加配准耗时、候选数和因状态改变丢弃结果数诊断，以及可复用的录包定位检查命令。
