# 2026-10-28 稀疏支撑导致直线拒绝的修正

本轮仅在本机修改、构建及验证，没有连接或同步 NX，没有启动机器人驱动、运动桥接或真实运动测试。本文记录的是上一轮暂时关闭严格推断后的进一步修正，当前最终配置见下文。

## 根因及改动

原先的支撑推断把实测支撑的位置近似成规划栅格中心。当前规划分辨率 0.1 m，来自地形地图的实测点却不一定在这些中心上，XY 可出现约 0.05 m 偏置。用近似位置判断包围关系会拒绝实际有周围地面证据的小空缺。

同时，旧推断开关会停用原来的邻近支撑回退。上一轮先关闭它恢复原行为；本轮将它改为补充式插值，保留原有实测支撑选择。整段检查和路径点检查共享同一个地面解析规则，实测与原有实测邻点优先，插值只作补充。

本轮实现：

- 独立保留每个实测支撑层的真实 XY；高度合并、重新分层和 reset 时同步维护。地图文件、输入消息和地图身份校验不变。
- 用实测 XY 构造同层支撑的凸包，即这些观测点实际包围的范围。只有整个规划栅格的四个角都在该范围内，才缓存插值结果。搜索节点仍用栅格中心，不改 TF 或里程计坐标。
- 保留高度跨度、拟合残差、坡度、多层歧义及缓存界限。邻近高度带中与拟合平面矛盾的观测也会否决插值，不能通过分组丢掉台阶证据。
- 推断地面不参与下一轮推断；所有原有障碍、坡度、台阶和完整矩形扫掠检查继续执行。

只检查格子中心会使细小三角片段通过搜索，却在路径加密后落到无支撑区域。新增固定端点对照暴露了这个问题，最终实现改为整格覆盖；缓存保持简单的整格结论，没有保留这条不完整做法。

## 最终默认配置

共享 `nav2_mppi_params.yaml` 当前为：

| 参数 | 值 |
| --- | --- |
| support_inference_enabled | true，补充式，不替换实测邻近支撑 |
| support_inference_radius | 0.4 m |
| support_inference_max_height_span | 0.06 m |
| support_inference_max_residual | 0.01 m |
| support_inference_max_slope_deg | 10° |

0.4 m 是当前 0.2 m 地形栅格中小空缺的局部拟合邻域，不是机器人半径或障碍膨胀半径。增加邻域不会直接把其中所有未知位置放行：仍须通过上述整格包围及平面检查。它是对小空缺地面连续性的假设，不是补充了真实观测，也不能证明未观测处没有坑洞。

本机在线、离线安装目录均已更新。核心库自身未提供配置时仍为 opt-in；正常启动使用共享参数文件。保留开关，可以关闭补充式插值进行对照。
